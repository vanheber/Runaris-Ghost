Guia de Instalação

Passo a passo para instalar o Runaris Ghost em uma máquina nova. Todos os dados ficam 100% locais — nada é enviado para a nuvem.

1O que você vai precisar
  • O pacote Windows já vem pronto — o PHP e todas as bibliotecas estão embutidos dentro da pasta runtime/. Nada a instalar.
  • Um navegador — Chrome, Firefox, Edge ou Safari.
  • ~300 MB de espaço livre em disco.
  • Opcional: Git e PHP — apenas se você for clonar o código-fonte em vez de usar o pacote ZIP.
Extensões necessárias do PHP: pdo_sqlite, mbstring, openssl, tokenizer, xml, ctype, json, fileinfo e bcmath. O assistente de instalação verifica tudo automaticamente e avisa se algo faltar.
2Instalando o PHP
Só necessário para quem vai rodar o código-fonte (git clone) em vez do pacote Windows. No pacote runaris-ghost-win.zip o PHP já vem embutido em runtime/ — pule esta seção.

Escolha o seu sistema. Ao final, confirme abrindo o Terminal (ou Prompt de Comando) e digitando:

php -v

Opção A (recomendada) — Homebrew:

brew install php

Opção B — Laravel Herd: baixe em herd.laravel.com e instale. Ele traz o PHP pronto, sem comandos.

Se o Terminal não achar o php depois do Homebrew, reinicie o Terminal e tente de novo.

Opção A (recomendada) — PHP oficial:

  1. Baixe o ZIP em windows.php.net/download (versão x64 Thread Safe).
  2. Extraia o conteúdo para uma pasta, ex.: C:\php.
  3. Copie php.ini-development para php.ini (mesma pasta).
  4. Adicione C:\php às Variáveis de Ambiente (PATH) do Windows.
  5. Se o Windows pedir, instale também o Visual C++ Redistributable.

Opção B — XAMPP: instale o XAMPP e marque a opção PHP. Depois use o php.exe da pasta C:\xampp\php.

Debian / Ubuntu:

sudo apt update && sudo apt install php-cli php-sqlite3 php-mbstring php-xml php-bcmath php-gd php-zip

Fedora / RHEL:

sudo dnf install php-cli php-pdo php-mbstring php-xml php-bcmath php-gd php-zip

Após instalar, confira com php -v em um terminal novo.

3Instalando o Runaris Ghost (Windows)
  1. Baixe o pacote runaris-ghost-win.zip (73 MB) — download direto da última versão. Todos os arquivos ficam em Releases.
    O pacote contém o código, todas as dependências e o PHP embutido — nada a instalar.
  2. Extraia o ZIP completo para onde o app vai morar, por exemplo: 
    C:\Runaris-Ghost
    Extraia tudo — inclusive a pasta runtime/. Na raiz existe um index.html (dê dois cliques) com estas mesmas instruções.
  3. Dê dois cliques em start.bat.
    Uma janela preta abre, o navegador é aberto sozinho no assistente de instalação. Deixe essa janela aberta enquanto usa o app; feche-a para encerrar.
  4. Se o Windows avisar sobre um "aplicativo não reconhecido", clique em Mais informações → Executar mesmo assim. É o seu próprio programa local.
  5. Pronto: siga o assistente (próxima seção).
Alterar a porta

O start.bat detecta uma porta livre automaticamente (geralmente http://127.0.0.1:8000). Para fixar outra, basta iniciar a instalação por um servidor próprio apontado para a pasta public/ — nunca para a raiz do projeto.

Primeira abertura no macOS: o sistema pode avisar que o arquivo é de desenvolvedor não identificado. Clique com o botão direito em start.command → Abrir. O launcher já remove a quarentena do runtime embutido sozinho.

Direto do código-fonte — para desenvolvimento ou arquitetura fora do pacote (ex.: Mac Intel):

composer install
npm ci && npm run build      # só na primeira vez (gera public/build)
./start.sh                   # Linux — ou ./start.command no macOS
  • O launcher aplica a atualização pendente, acha uma porta livre, abre o navegador e serve a pasta public/.
  • Sem tela (VPS/SSH): NO_BROWSER=1 ./start.sh — a URL aparece no terminal.
  • Reverter a última atualização: ./start.sh --rollback (ou php artisan app:rollback).
  • No código-fonte o npm run build é obrigatório: sem public/build o app responde erro 500 (o Laravel procura o manifest do Vite).
4O assistente de instalação

O assistente guia você até o fim — são 5 passos rápidos:

  1. Verificação de requisitos — confere versão do PHP, extensões e permissões de escrita. Se algo faltar, a tela diz exatamente o quê (o mais comum é uma extensão desativada no php.ini).
  2. Banco de dados — cria o arquivo SQLite automaticamente, sem configuração.
  3. Seu usuário — cria o seu login local (admin).
  4. Chave da IA (opcional) — pode pular; dá pra adicionar depois em Configurações. A IA é totalmente opcional.
  5. Concluir — fecha o assistente e libera o Santuário.
Pronto! Seus manuscritos ficam em Markdown puro dentro da pasta storage/ — legíveis por humanos, sem amarras. Faça backups em Configurações → Backup Total do Sistema.
Como atualizar (Windows)

Pelo pacote Windows, a atualização é feita pelo próprio app — seus dados nunca são tocados:

  1. Abra Configurações → Guardião (aba Sistema).
  2. Quando houver versão nova, clique em Instalar Versão X. O pacote é baixado em segundo plano.
    Preferiu continuar na versão atual? Clique em Manter versão atual — não avisaremos mais sobre aquela versão.
  3. Feche a janela preta do start.bat e execute o start.bat novamente — ele aplica a atualização antes de iniciar.
  4. Se algo der errado, o start.bat reverte sozinho para a versão anterior. Para reverter manualmente, rode o rollback.bat.
Por que assim? Os arquivos database/database.sqlite, storage/ (projetos e backups) e .env nunca entram no pacote de atualização — ficam no lugar. O botão "Atualizar Sistema" só mostra a opção "Desfazer atualização" em instalações por git clone; no pacote Windows, o rollback é o rollback.bat.
macOS/Linux: instalação por pacote aplica a atualização no boot do launcher (php artisan app:apply-update) e reverte com ./start.sh --rollback (php artisan app:rollback). O snapshot fica em storage/updates/previous. Instalação por git clone continua atualizando com git pull.
Privacidade por princípio

Zero telemetria. Nenhum dado seu sai da máquina — exceto, se você configurar, as chamadas à API do Google Gemini para os botões de IA. Todo o conteúdo é armazenado localmente em arquivos .md e SQLite, sob total controle seu.
