Guia de Instalação

Passo a passo para instalar o Runaris Ghost em uma máquina nova. Todos os dados ficam 100% locais — nada é enviado para a nuvem.

1O que você vai precisar
  • PHP 8.3 ou superior — é a única dependência de sistema. O pacote de instalação já traz todo o resto (bibliotecas e interfaces compiladas).
  • Um navegador — Chrome, Firefox, Edge ou Safari.
  • ~300 MB de espaço livre em disco.
  • Opcional: Git — apenas se você for clonar o código-fonte em vez de usar o pacote ZIP.
Extensões necessárias do PHP: pdo_sqlite, mbstring, openssl, tokenizer, xml, ctype, json, fileinfo e bcmath. O assistente de instalação verifica tudo automaticamente e avisa se algo faltar.
2Instalando o PHP

Escolha o seu sistema. Ao final, confirme abrindo o Terminal (ou Prompt de Comando) e digitando:

php -v

Opção A (recomendada) — Homebrew:

brew install php

Opção B — Laravel Herd: baixe em herd.laravel.com e instale. Ele traz o PHP pronto, sem comandos.

Se o Terminal não achar o php depois do Homebrew, reinicie o Terminal e tente de novo.

Opção A (recomendada) — PHP oficial:

  1. Baixe o ZIP em windows.php.net/download (versão x64 Thread Safe).
  2. Extraia o conteúdo para uma pasta, ex.: C:\php.
  3. Copie php.ini-development para php.ini (mesma pasta).
  4. Adicione C:\php às Variáveis de Ambiente (PATH) do Windows.
  5. Se o Windows pedir, instale também o Visual C++ Redistributable.

Opção B — XAMPP: instale o XAMPP e marque a opção PHP. Depois use o php.exe da pasta C:\xampp\php.

Debian / Ubuntu:

sudo apt update && sudo apt install php-cli php-sqlite3 php-mbstring php-xml php-bcmath php-gd php-zip

Fedora / RHEL:

sudo dnf install php-cli php-pdo php-mbstring php-xml php-bcmath php-gd php-zip

Após instalar, confira com php -v em um terminal novo.

3Instalando o Runaris Ghost
  1. Baixe o pacote runaris-ghost-dist.zip do projeto no GitHub (github.com/vanheber/Runaris-Ghost).
    O pacote já contém todo o código e todas as dependências PHP — não é preciso rodar Composer nem npm.
  2. Extraia o ZIP para onde o app vai morar, por exemplo: 
    ~/Runaris-Ghost          (macOS/Linux)
C:\Runaris-Ghost         (Windows)
  3. Abra o Terminal dentro da pasta extraída e rode: 
    php artisan serve
    Para usar outra porta: php artisan serve --port=8080
  4. Abra o navegador em http://127.0.0.1:8000 — o assistente de instalação aparece automaticamente.
Alternativa: servidor web próprio

Se você prefere Apache/Nginx/Herd em vez de php artisan serve, aponte o document root do servidor para a pasta public/ dentro da instalação — nunca para a raiz do projeto. Depois acesse o endereço do servidor no navegador.

4O assistente de instalação

O assistente guia você até o fim — são 5 passos rápidos:

  1. Verificação de requisitos — confere versão do PHP, extensões e permissões de escrita. Se algo faltar, a tela diz exatamente o quê (o mais comum é uma extensão desativada no php.ini).
  2. Banco de dados — cria o arquivo SQLite automaticamente, sem configuração.
  3. Seu usuário — cria o seu login local (admin).
  4. Chave da IA (opcional) — pode pular; dá pra adicionar depois em Configurações. A IA é totalmente opcional.
  5. Concluir — fecha o assistente e libera o Santuário.
Pronto! Seus manuscritos ficam em Markdown puro dentro da pasta storage/ — legíveis por humanos, sem amarras. Faça backups em Configurações → Backup Total do Sistema.
Como atualizar

Em instalações pelo pacote ZIP, a atualização é feita "por cima" — seus dados nunca são tocados:

  1. Baixe o novo runaris-ghost-dist.zip.
  2. Extraia por cima da pasta onde o app está instalado, substituindo os arquivos: 
    unzip -o runaris-ghost-dist.zip -d ~/Runaris-Ghost   (macOS/Linux)
    No Windows: extraia e escolha "Substituir arquivos no destino".
  3. Reinicie o servidor: encerre o php artisan serve (Ctrl + C) e rode de novo.
  4. Abra o navegador — pronto, versão atualizada.
Por que assim? Os arquivos database/database.sqlite, storage/ (projetos e backups) e .env não vêm no ZIP — eles ficam no lugar. O botão "Atualizar Sistema" dentro de Configurações só funciona em instalações feitas por git clone; numa instalação por ZIP, use este procedimento.
Privacidade por princípio

Zero telemetria. Nenhum dado seu sai da máquina — exceto, se você configurar, as chamadas à API do Google Gemini para os botões de IA. Todo o conteúdo é armazenado localmente em arquivos .md e SQLite, sob total controle seu.
