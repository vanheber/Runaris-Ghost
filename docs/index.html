Runaris Ghost

Este pacote já vem completo. Você só precisa do PHP e de 3 passos para instalar. Todos os dados ficam 100% locais.

1Instale o PHP 8.3+

Dependência única. Escolha o seu sistema:

  • macOS: Homebrew — brew install php, ou Laravel Herd.
  • Windows: windows.php.net (x64) ou XAMPP.
  • Linux: debian/ubuntu — sudo apt install php-cli php-sqlite3 php-mbstring php-xml php-bcmath php-gd php-zip

Confira abrindo o terminal e digitando php -v. Ver guia completo com todos os detalhes →

2Inicie o servidor

Abra o Terminal (Prompt de Comando no Windows) dentro desta pasta e rode:

php artisan serve

Deixe essa janela aberta enquanto usa o aplicativo. Para parar, pressione Ctrl + C.

3Abra o instalador

Com o servidor do passo 2 rodando, o assistente estará pronto:

Verificando se o servidor está ativo…
Abrir instalador
http://127.0.0.1:8000/install

Não é preciso instalar Composer nem Node.js — as dependências já vêm embutidas neste pacote.
