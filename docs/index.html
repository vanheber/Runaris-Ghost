Como instalar

  1. 1
    Extraia o ZIP completo

    Botão direito no runaris-ghost-win.zip → Extrair tudo. Inclua a pasta runtime/.

  2. 2
    Dê dois cliques em 
    start.bat

    Uma janela preta abre e fica aberta enquanto você usa o app. Feche-a para encerrar.

  3. 3
    O navegador abre sozinho

    No assistente de instalação: requisitos, banco, seu usuário e — opcional — a chave de IA.

  1. 1
    Extraia o ZIP

    Dois cliques no runaris-ghost-mac-arm64.zip — o Finder cria a pasta com o app.

  2. 2
    Primeira abertura

    Clique com o botão direito em start.command → Abrir. O macOS avisa que o arquivo é de desenvolvedor não identificado; é o seu próprio programa local.

  3. 3
    O navegador abre sozinho

    O Terminal fica aberto com o servidor. Ctrl+C ou fechá-lo encerra o app.

  1. 1
    Extraia e rode 
    unzip runaris-ghost-linux-x64.zip -d runaris-ghost
cd runaris-ghost && ./start.sh
  2. 2
    Se o script não abrir

    Alguns gerenciadores de arquivo perdem a permissão de execução:

    chmod +x start.sh start-mcp.sh runtime/frankenphp
  3. 3
    O navegador abre sozinho

    Sem interface gráfica (VPS/SSH)? NO_BROWSER=1 ./start.sh imprime a URL no terminal.

Não é preciso instalar PHP, Composer nem Node.js — tudo vem embutido no pacote. Reserve ~300 MB de espaço livre.

Atualizar

Pelo próprio app: Configurações → Guardião. O pacote é baixado e aplicado na próxima abertura. Seus manuscritos, seu banco e sua configuração nunca são tocados.

Reverter

rollback.bat no Windows · ./start.sh --rollback no macOS/Linux. O snapshot da versão anterior fica em storage/updates/previous.
