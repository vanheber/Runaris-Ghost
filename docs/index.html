Santuário Digital para Autores

Este pacote já vem completo — inclusive o PHP. São 2 passos para instalar. Todos os dados ficam 100% locais.

1Extraia o pacote

Clique com o botão direito no runaris-ghost-win.zip e escolha "Extrair tudo".

  • Uma pasta runaris-ghost será criada.
  • Não é preciso instalar PHP. O runtime já vem dentro do pacote.

Ver guia completo com todos os detalhes →

2Rode o start.bat

Dentro da pasta extraída, dê dois cliques em:

start.bat

Uma janela preta de servidor abre e fica aberta enquanto você usa o aplicativo. Para encerrar, feche a janela.

3O navegador abre sozinho

O start.bat abre o navegador no assistente de instalação automaticamente:

Assistente em http://127.0.0.1:8000/install

Siga os passos do assistente: requisitos, idioma, banco, usuário e — opcional — sua chave de IA.

Não é preciso instalar PHP, Composer nem Node.js — tudo já vem embutido neste pacote.
