# Guia de Contribuição - Runaris Ghost

Bem-vindo ao Santuário. Somos um projeto Open Source que valoriza a privacidade e a imersão na escrita.

## ⚖️ Nosso Modelo de Negócio
Para manter o desenvolvimento sustentável, operamos no modelo **"Support is Paid"**.
- O código fonte é aberto para auditoria e contribuições.
- Builds oficiais assinadas e suporte técnico direto são exclusivos da versão paga.

## 🤝 Como Contribuir

### 1. Relato de Bugs
Se você encontrar um problema técnico no código:
1. Verifique se ele ocorre na versão compilada a partir da `main`.
2. Abra uma Issue detalhando o comportamento esperado vs. atual.
3. Não abrimos Issues para problemas de configuração de ambiente local (PHP, Node, etc).

### 2. Pull Requests (PRs)
- **Foco em UI**: Seguimos rigorosamente o **Bootstrap 5.3**. Não aceitamos Tailwind ou outros frameworks de CSS.
- **Backend**: Mantenha a simplicidade do Laravel 11.
- **Privacidade**: Nunca adicione telemetria ou chamadas a APIs sem o consentimento explícito do usuário.

## ⚠️ Regras de Suporte
**NÃO oferecemos suporte para builds manuais.** Se você está tentando compilar e o `composer install` falhou, por favor, busque soluções na comunidade Laravel ou do seu Sistema Operacional. 

Se você quer que o software "simplesmente funcione", por favor, apoie o projeto adquirindo a [versão oficial](https://gumroad.com).
